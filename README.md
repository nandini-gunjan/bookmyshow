# bookmyshow

It is a clone of BookMyShow website with some additional features and improvement.

# Programming languages & tools used:

1. HTML & CSS - For structure & styling
2. JS - For backend
3. Firebase

- Authentication
- Firestore

4. TMDb API - For movies poster & information
5. Ticketmaster Discovery API - For events & plays information
6. Sports API - For sports information
